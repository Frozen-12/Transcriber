# Транскрибатор — аудио/видео в текст

Настольная программа для Windows: быстрое распознавание речи из аудио и видео файлов локально, на вашем компьютере. Движок — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (CTranslate2), на видеокарте NVIDIA распознаёт в 15–25 раз быстрее длительности записи; без видеокарты работает на процессоре.

## Возможности

- **Выбор модели**: tiny … large-v3, large-v3-turbo, distil-large-v3 — компромисс скорость/качество.
- **Оценка времени** до старта обработки (после первого файла калибруется по реальному замеру на вашем железе).
- **Слежение за папкой**: новые аудио/видео файлы автоматически попадают в очередь и обрабатываются; по завершении — уведомление, куда всё сложено.
- **Папка проекта**: после обработки исходник и результаты (.txt / .srt) автоматически переносятся в выбранную папку. Не выбрана — всё остаётся рядом с файлом.
- **Структурированный .txt** с таймкодами `[мм:сс]` (отключается) и/или субтитры `.srt`.
- **ИИ-обработка результата** (кнопка ☰ → Настройки): после распознавания текст отправляется любой консольной нейросети (пресеты Kimi CLI и Ollama или своя команда; текст уходит в stdin), ответ сохраняется в `<имя>.ai.txt` и переезжает в папку проекта вместе с остальными файлами.
- **Иконка в трее** и автозапуск с Windows (галочка в шапке).
- Тёмная тема, чёткие шрифты на мониторах с масштабированием (2K/4K).
- Все настройки сохраняются между запусками (`transcriber_config.json` рядом с программой).

## Установка из исходников

```powershell
python -m venv venv
venv\Scripts\pip install -r requirements.txt
# для видеокарты NVIDIA дополнительно:
venv\Scripts\pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
python transcriber.py
```

Модель распознавания скачается автоматически при первом запуске обработки (в папку `models` рядом с программой; large-v3-turbo ≈ 1,6 ГБ). Нужен интернет один раз.

## Сборка portable .exe

```powershell
venv\Scripts\pip install pyinstaller
venv\Scripts\python -m PyInstaller --noconfirm --windowed --name Transcriber `
  --collect-all ctranslate2 --collect-all faster_whisper --collect-all av `
  --collect-all tokenizers --collect-all onnxruntime --collect-all huggingface_hub `
  --collect-all pystray `
  --add-data "venv\Lib\site-packages\nvidia;nvidia" transcriber.py
```

Готовая программа — в `dist\Transcriber\`. Папку можно копировать на другой компьютер как есть (Windows 10/11 64-бит; без видеокарты NVIDIA будет работать на процессоре).

## Как пользоваться

1. Выберите модель (рекомендуется `large-v3-turbo`), устройство и язык.
2. Добавьте файлы кнопкой «Выбрать файлы…» / «Обработать папку…» или включите слежение за папкой.
3. При желании укажите «Папку проекта» — туда переедут исходники и результаты.
4. Нажмите «Начать обработку». Двойной клик по готовому файлу открывает текст.
